## 二、信号定义（每月检视 1 次）

- **动量** = 今日 QQQ 收盘价 ÷ 约13个月前 QQQ 收盘价 − 1（即过去12个月涨跌，跳过最近1个月防噪音）
- 动量 **> 0 → 上行态**；动量 **≤ 0 → 下行态**
- 信号看 **QQQ 美元价**（不是 017436 净值，它是主动型会偏离）；手机行情 App 或 monitor 页查

**每月具体做一次**：月末最后一个交易日收盘后，查 QQQ 现价 vs 13个月前收盘价，比大小即可，2分钟。

## 四、每月检视流程（三步）

1. **算动量** → 确定应处状态（上/下）
2. **看是否翻转**：应处状态 ≠ 当前状态 → 调仓到新目标（大动作，见第五节）
3. **看偏离带**：状态没变，但 QQQ 实际占比偏离目标 ≥ 5个百分点 → 调回目标（小动作）
   例如上行态但 QQQ 涨到 78% → 卖出 QQQ 回补黄金到 30%；下行态 QQQ 掉到 24% → 用现金买回 QQQ 到 30%
4. 都不满足 → 不用动，新钱按目标比例继续投

操作量：20年共 16 次翻转 + ~36 次偏离带调整 ≈ 每年 2~3 次实际动手。

## 五、翻转时的具体买卖

**上 → 下（如 2022-04 那种）**
1. 卖 QQQ：017436 赎回，无每日上限，T+2~T+7 到账。卖出金额 = 当前市值 ×（当前Q占比 − 30%）。例：组合¥200万、Q占70% → 赎回 ¥80万。
2. 到账后全部买入 511880 货币ETF（现金蓄水池）。
3. 黄金若超过30%（比如涨到38%），用 518880 场内卖出超出部分，同样进 511880。
4. 新钱改为下行态比例：¥1500 Q + ¥1500 金 + ¥2000 现金。

**下 → 上（如 2023-05 那种）**
1. 目标变回 70/30。回补 QQQ 受 017436 日限购 ¥1000 限制，**慢慢买不着急**（回测证明：回补上限压到 ¥2.2万/月，收益只差 0.03pp，慢慢买反而摊平成本）。
2. 操作顺序：① 新钱全部按上行态 70/30 投；② 每月额外用 511880 现金 + 卖出超出30%的黄金，按日 ¥1000 补 QQQ，直到 Q 占比回到 70%。
3. 补仓期可能持续数月甚至一年，期间组合是「Q偏低+现金偏高」，这是正常状态，不要焦虑。

## 七、纪律与边界

1. **信号接近 0**：动量 ≤ 0 一律按下行态处理（回测就是这么算的），别纠结 ±1%。
2. **震荡年**（回测里 2016 年翻转过 4 次）：属正常，当时仓位小、动作金额小，照做即可；不要因此去"等确认"。
3. **不做叠加**：不叠加 MA200、网格、双动量——回测均无正贡献或不可执行。
4. **现金别躺活期**：下行态 40% 现金放 511880。
5. **卖金抄底是禁区**：任何情况下不要用「卖黄金换 QQQ 抄底」，回测已证负优化。
6. 最大风险仍是 017436 主动型偏离（YTD +4.2% vs QQQ +16.8%）——信号用 QQQ 价，执行分批、按净值算，若 017436 持续大幅跑输 QQQ 再单独评估换 场内 159632（溢价<2%才买）。
